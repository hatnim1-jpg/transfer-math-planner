# 편입수학 학습 플래너 (진행 중: STEP D까지)

2027학년도 편입수학 대비 모바일 우선 학습 플래너. 서버 없이 동작하며 데이터는 브라우저 LocalStorage(`planner.v1`)에 저장됩니다.

## 실행
`index.html`을 브라우저에서 열면 됩니다. 날짜 확인용으로 `index.html?today=2026-12-04`처럼 오늘 날짜를 바꿔 볼 수 있습니다.
GitHub Pages: 저장소에 이 폴더 내용을 올리고 Settings → Pages에서 브랜치 루트를 선택하세요.

## 구현 현황
- 완료: STEP A(강의 데이터·일정 엔진), STEP B(오늘 대시보드, 캘린더, 컨디션, 한 줄 기록, 시험일 설정 — 1/9 한양대, 1/10 중앙대), STEP C(강의 편집·추가·상태 변경, 루틴 추가/삭제, 복습 이해도 기록, 틀린 문제·재도전 관리, 기출/일반 구분)
- 완료(STEP D): 컨디션 모드(회복/기본/집중)별 일정, 일정 다시 맞추기(전후 비교 미리보기 → 확인 후 적용), 오늘부터 다시 시작하기, 개별 휴식일 지정/해제, 공부 시간·휴식 요일·완강 목표일 변경, 불가능할 때 대안(완강일 연장·공부 시간·우선순위 재검토)
- 미구현: 타이머·통계·JSON 백업·데이터 초기화(STEP E)
- 일정 재계산 규칙: 완료한 강의와 지난 날짜 기록은 이동하지 않고, 미완료 강의는 오늘부터 순서·선수학습·하루 공부 가능 시간을 지켜 다시 배치합니다. 변경은 항상 미리보기를 확인한 뒤에만 적용됩니다.

## 강의 데이터
출처: 김영편입 공식 강좌 페이지의 2027 장황수학 White 강의목차(2026-11-23 조회) — 선형대수 35강, 다변수미적분 42강, 공학수학 24강.
제목·시간은 공식 표 기준이며, 개념/문제풀이 구분은 제목 기준입니다. 문제풀이 전용으로 제외한 13강(다변수 8·13·17·24·25·26·33·41·42, 공학수학 12·13·14·15)은 **검증 필요**입니다.
`node tools/build-lectures.js`로 `lectures.js`를 다시 생성합니다.

## 기본 일정 설정
시작 11/25, 개념 완강 목표 12/22, 시험일 1/9·1/10, 하루 4시간에서 최대 7.5시간까지 점진적 증가, 매주 수요일 휴식(시작일 11/25 제외).
최대 6시간으로는 12/22 완강이 불가능합니다(엔진이 불가능으로 판정하고 대안을 제시).

## STEP E 구현 현황 (타이머 · 통계 · 백업)

- **집중 타이머**: 강의 선택 후 25분/50분/직접 설정으로 시작, 일시정지·재개·종료 저장. 종료 시 휴식 5분·이어가기 선택. 하단 미니바로 진행 중 타이머를 어디서든 열 수 있어요.
- **5분만 시작하기**: 오늘 첫 미완료 강의로 5분 타이머를 시작하고, 끝나면 25분 더/휴식/여기까지 중에서 고르게 해요.
- **휴식 타이머**: 5·10·15분.
- **브라우저를 닫아도 복구**: 진행 중에는 1초마다 마지막 확인 시각을 저장하고, 다시 열면 그 시점까지의 시간만 복구해 일시정지 상태로 보여줘요. 닫혀 있던 시간은 공부 시간에 넣지 않아요.
- **실제 공부 시간 vs 예상 시간**: 타이머로 잰 시간만 ‘실제 측정’으로 집계하고 계획상 예상 시간과 따로 보여줘요. 10초 미만 기록은 저장하지 않아요.
- **통계 탭**: 강의 완료율(전체·과목별), 누적/최근 7일 공부 시간 막대, 주간 계획 달성률, 과목별 복습 현황, 목표 완강일 대비 진행, 남은 강의 예상 총 소요 시간. 제외한 강의는 계산에서 빼요.
- **데이터 관리(설정)**: 백업 다운로드(JSON), 백업 불러오기(형식 검증 후 확인), 모든 데이터 초기화(확인 2회).

### 알려진 한계
- 타이머는 브라우저 탭이 백그라운드일 때 알림음을 내지 못해요(진동은 기기가 지원할 때만). 다시 열면 시간이 정확히 반영돼요.
- 백업은 사용자가 직접 받아야 해요. 자동 클라우드 동기화는 없어요.

### 실행 방법
1. 폴더를 그대로 두고 `index.html`을 브라우저에서 열어요(서버·설치 불필요, 오프라인 동작).
2. 날짜 확인용: 주소 끝에 `?today=2026-12-01`처럼 붙이면 그 날짜 기준으로 볼 수 있어요.

### GitHub Pages 배포
1. 새 저장소를 만들고 이 폴더의 파일(`index.html`, `style.css`, `app.js`, `engine.js`, `lectures.js`, `README.md`)을 올려요.
2. Settings → Pages → Branch를 `main` / `(root)`로 지정하면 몇 분 뒤 주소가 생겨요.
3. 데이터는 접속한 기기의 브라우저에 저장돼요. 기기를 바꾸려면 설정에서 백업을 받아 옮기세요.

### 데이터 출처와 검증 필요 항목
- 강의 목록·시간은 김영편입 장황수학 White 공식 강의 목록 표에서 가져왔고(수집일 2026-11-23), 합계 체크섬으로 대조했어요.
- **검증 필요**: (1) 문제풀이 전용 13개는 제목(‘유형별’·‘단단’) 기준 판단이에요. 실제 내용이 개념을 포함하면 ‘강의’ 탭에서 포함으로 바꿀 수 있어요. (2) 강의 시간은 요약 도구로 읽은 값이라 몇 개는 공식 페이지와 직접 대조해 보세요. (3) 선형대수 남은 강의 외 진도는 사용자 입력 기준이에요.

### 저장·백업
- 모든 기록은 LocalStorage(키 `planner.v1`)에 자동 저장돼요. 브라우저 데이터를 지우면 사라져요.
- 설정 → 데이터 관리에서 JSON 백업 다운로드·불러오기·초기화를 할 수 있어요.

### 수정 방법
- 강의 데이터: `tools/build-lectures.js`의 원본 표를 고치고 `node tools/build-lectures.js`로 `lectures.js`를 다시 만들어요. 앱 안의 ‘강의’ 탭에서도 개별 강의의 시간·상태·메모를 바꿀 수 있어요.
- 기본값(최대 시간, 쉬는 요일, 시험일, 배속 등): `engine.js` 맨 위 `DEFAULTS` 또는 앱 설정 화면.
